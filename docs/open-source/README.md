## 使用入口

1. 按 [快速开始](quickstart.md) 在独立环境配置数据库、Redis 和 API。
2. 按 [演示说明](../../examples/public-demo/README.md) 导入流程，先执行 Mock 检查，再配置真实通话。
3. 按 [评估说明](asr-evaluation.md) 记录真实识别结果，不将 Mock 指标并入实测。
4. 按 [导出与校验说明](release.md) 生成源码包，审阅 `release-report.json` 和 `source-manifest.json`。

本次验证的具体命令、结果及边界见 [验证记录](verification.md)。
